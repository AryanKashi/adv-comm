# ⚡ Advanced Professional Communication (ADV COMM)
### *Interactive 50-Question Quiz Hub & Anime Study Masterwork*

Welcome to the **Advanced Professional Communication (ADV COMM)** Interactive Study Portal! This repository hosts an interactive web application with 50 placement and exam questions, model answers, in-depth technical explanations, and anime-inspired narrative anchors covering the full course syllabus.

## 🚀 How to Enable GitHub Pages
1. Go to your repository on GitHub: **[AryanKashi/adv-comm](https://github.com/AryanKashi/adv-comm)**
2. Click on **Settings** (gear icon in the top navigation).
3. In the left sidebar, click on **Pages** (under the "Code and automation" section).
4. Under **Build and deployment** ➜ **Branch**:
   - Select **`main`** from the branch dropdown.
   - Leave the folder as **`/(root)`**.
   - Click **Save**.
5. Wait ~30 to 60 seconds, and refresh! Your live website URL will appear at the top of the Pages section!

## 🎯 Features of the Web App
- **Interactive Question Palette (1–50):** Jump to any question instantly via the right-hand sidebar.
- **Visual Feedback:** Color-coded badges for Active (🔵), Unanswered (⚪), Correct (🟢), and Incorrect (🔴).
- **Single Question Focus:** Only one question at a time to maximize retention.
- **Detailed Explanations:** Real-time answer reveals with textbook citations and anime memory anchors.
- **Live Score & Progress Bar:** Track your percentage completion and points in real time.
- **Keyboard Shortcuts:**
  - `←` / `→`: Navigate between questions.
  - `1`, `2`, `3`, `4`: Select Option A, B, C, or D.
  - `Enter`: Submit answer.
